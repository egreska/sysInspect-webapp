───────────────────────────────────────────────────────────────
  STEP 2: COOLIFY ROUTING CONFIGURATION
───────────────────────────────────────────────────────────────

🚨 CRITICAL: You MUST configure TWO ports in Coolify!

Option A - Coolify UI (If Available):
  Navigate to: Application → Network → Routing
  
  Primary Port:
    Port: 5173 (Frontend)
    Path: /
  
  Additional Port:
    Port: 3002 (Backend)
    Path: /api
    Strip Prefix: NO

Option B - Docker Labels (If UI routing not available):
  Navigate to: Application → Advanced → Docker Labels
  
  Add these labels:
  
  traefik.http.routers.app-api.rule=Host(`sysinspect.skynet97.org`) && PathPrefix(`/api`)
  traefik.http.routers.app-api.service=app-api
  traefik.http.services.app-api.loadbalancer.server.port=3002
  traefik.http.routers.app-api.priority=10
  
  traefik.http.routers.app-web.rule=Host(`sysinspect.skynet97.org`)
  traefik.http.routers.app-web.service=app-web
  traefik.http.services.app-web.loadbalancer.server.port=5173
  traefik.http.routers.app-web.priority=1

───────────────────────────────────────────────────────────────
  HOW IT WORKS
───────────────────────────────────────────────────────────────

Request Flow:
  Browser → Cloudflare → Coolify → Traefik
                                      ├─ / → Port 5173
                                      └─ /api → Port 3001

Container:
  ├─ Frontend (serve -s dist -l 5173)
  └─ Backend (node src/index.js on port 3002)
