PROBLEM: Blank screen with console error "t.slice(...).map is not a function"

CAUSE: CloudKit environment variables not configured in Coolify

═══════════════════════════════════════════════════════════════
  ✅ IMMEDIATE FIX
═══════════════════════════════════════════════════════════════

1. Push the fix:
   git push origin main

2. Add these 5 environment variables in Coolify:

   CLOUDKIT_CONTAINER_ID=<from Xcode>
   CLOUDKIT_ENVIRONMENT=production
   CLOUDKIT_API_TOKEN=<from CloudKit Dashboard>
   CLOUDKIT_SERVER_KEY_ID=<from .p8 file>
   CLOUDKIT_PRIVATE_KEY="<content of .p8 file>"

3. Redeploy in Coolify

───────────────────────────────────────────────────────────────
  WHERE TO GET THE VALUES
───────────────────────────────────────────────────────────────

CLOUDKIT_CONTAINER_ID:
  Xcode → Target → Signing & Capabilities → iCloud
  Example: iCloud.com.yourcompany.SystemsInspector

CLOUDKIT_API_TOKEN & SERVER_KEY_ID:
  1. Go to: https://icloud.developer.apple.com/dashboard
  2. Select your container
  3. API Access → Create Server-to-Server Key
  4. Download the .p8 file (save the Key ID)
  5. Generate API Token

CLOUDKIT_PRIVATE_KEY:
  Open the downloaded .p8 file:
  cat ecdsaPrivateKey.p8
  
  Copy everything including:
  -----BEGIN PRIVATE KEY-----
  (key content)
  -----END PRIVATE KEY-----
